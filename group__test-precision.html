#include <tts/test/precision.hpp>

Checks that two values are at most N apart.

Measures the distance abs(L - R) with tts::absolute_check.

L and R must be of the same type, or the check does not compile.

Parameters
L,RValues to compare.
NLargest distance accepted.
...REQUIRED ends the run when the check fails.

Example

#define TTS_MAIN // No need for main()
#include <tts/tts.hpp>
TTS_CASE("Absolute distance")
{
TTS_ABSOLUTE_EQUAL(-2., 2., 4.);
TTS_ABSOLUTE_EQUAL(static_cast<long long>('A'), 80LL, 15, REQUIRED);
};

Checks that two values are 0 ULP apart, that is equal or both NaN.

Compares with tts::ieee_check, which uses operator== and counts two NaNs as equal, the 0 ULP case of TTS_ULP_EQUAL without measuring a distance.

Parameters
L,RValues to compare.
...REQUIRED ends the run when the check fails.

Example

#define TTS_MAIN // No need for main()
#include <tts/tts.hpp>
TTS_CASE("ULP distance")
{
float x = std::numeric_limits<float>::quiet_NaN();
TTS_IEEE_EQUAL(x, x);
TTS_IEEE_EQUAL(1.f, 1.f);
TTS_IEEE_EQUAL(2., 2.);
TTS_IEEE_EQUAL(65, 'A');
};

#define TTS_RELATIVE_EQUAL ( L,
R,
N,
... )

#include <tts/test/precision.hpp>

Checks that two values are within a combined relative and absolute tolerance N.

Passes if abs(L - R) <= N * max(1, abs(L), abs(R)), the combined tolerance test of tts::relative_check. N acts as an absolute tolerance where both values are at most 1 in magnitude, and as a relative one elsewhere. Two NaNs or two equal infinities pass, and any other NaN or infinity fails.

N is a ratio, so 0.005 accepts half a percent. On an arithmetic type, a finite N of 1 or more fails the check with a message asking for N divided by a hundred, since TTS 3 took a percentage.

L and R must be of the same type, or the check does not compile.

Parameters
L,RValues to compare.
NTolerance, as a ratio.
...REQUIRED ends the run when the check fails.

Example

#define TTS_MAIN // No need for main()
#include <tts/tts.hpp>
TTS_CASE("Relative distance")
{
TTS_RELATIVE_EQUAL(42.f, 42.f, 0);
TTS_RELATIVE_EQUAL(static_cast<long long>('A'), 80LL, 0.1875);
TTS_RELATIVE_EQUAL(1., 2., 0.5);
TTS_RELATIVE_EQUAL(1, 10, 0.9, REQUIRED);
};

R,

#include <tts/test/precision.hpp>

Checks that two values are at most N ULP apart.

Measures the distance with tts::ulp_check. See the ULP rationale for how the distance is measured.

L and R must be of the same type, or the check does not compile. The distance would be measured after promotion to the common type, in the ULP of that type and not of the type under test.

Parameters
L,RValues to compare.
NLargest distance accepted, in ULP.
...REQUIRED ends the run when the check fails.

Example

#define TTS_MAIN // No need for main()
#include <tts/tts.hpp>
TTS_CASE("ULP distance")
{
float a {1};
float eps = std::numeric_limits<float>::epsilon();
float qnan = std::numeric_limits<float>::quiet_NaN();
float inf = std::numeric_limits<float>::infinity();
float minf = -inf;
TTS_ULP_EQUAL(a, a, 0.);
TTS_ULP_EQUAL(a, qnan, inf);
TTS_ULP_EQUAL(qnan, qnan, 0.);
TTS_ULP_EQUAL(a, inf, inf);
TTS_ULP_EQUAL(inf, inf, inf);
TTS_ULP_EQUAL(minf, minf, inf);
TTS_ULP_EQUAL(a, a - eps, 1);
TTS_ULP_EQUAL(a, a + eps, 0.5);
TTS_ULP_EQUAL(a, a + 3 * eps, 1.5, REQUIRED);
};

#define TTS_ULP_RANGE_CHECK ( Producer,
RefType,
NewType,
RefFunc,
NewFunc,
... )

#include <tts/test/ranges.hpp>

Checks a function against a reference over a data set, within a given ULP distance.

Evaluates NewFunc and RefFunc on the same data set and sorts the ULP distance between their results into a histogram. The check passes when the largest distance stays within the bound given after NewFunc. The data set holds at least --block values, 4096 by default, and the generator builds each value from its index. --ulpmax replaces the bounds for every check of the run.

A function of several arguments takes tts::types lists as RefType and NewType, with the types in call order. Its generators are given between parentheses, as many as arguments, or as a single generator shared by all arguments. Each generator then produces the smallest number of values whose product over the arguments reaches --block: 64 values for two arguments by default. The data set covers every combination of these values.

NewType may hold several values of RefType, as a specialization of tts::adapter describes.

std::pair, std::tuple, and any result type that specializes std::tuple_size and provides a get found by argument-dependent lookup are tuples, unless tts::adapter is specialized for them. The members of a tuple are compared separately, each with its own histogram, and the check takes a bound for all members or a bound per member.

A check that fails prints its histogram, and every check prints it under --verbose. Each bucket shows the first element whose distance falls in it, with the results of the last pass under --loop. When NewType holds several values, that element is marked between stars within its group.

Parameters
ProducerData generator, or a generator per argument between parentheses.
RefTypeArgument type of the reference function, or a tts::types list of them.
NewTypeArgument type of the challenger function, or a tts::types list of them.
RefFuncReference function.
NewFuncFunction compared to the reference.
...Largest ULP distance accepted, or one per member of a tuple result.

Example

#define TTS_MAIN // No need for main()
#include <tts/tts.hpp>
#include <cmath>
#include <utility>
float my_ldexp(float x, int n)
{
return x * std::exp2(static_cast<float>(n));
}
TTS_CASE("Check my_ldexp against std::ldexp")
{
auto std_ldexp = [](float x, int n) { return std::ldexp(x, n); };
// One generator per argument: every x is checked with every n from -32 to 31
TTS_ULP_RANGE_CHECK((tts::between(-1.f, 1.f), tts::ramp(-32)),
(tts::types<float, int>),
(tts::types<float, int>),
std_ldexp,
my_ldexp,
0.);
};
std::pair<float, int> my_frexp(float x)
{
int e = std::ilogb(x) + 1;
return {std::scalbn(x, -e), e};
}
TTS_CASE("Check my_frexp against std::frexp")
{
auto std_frexp = [](float x)
{
int e = 0;
float m = std::frexp(x, &e);
return std::pair {m, e};
};
// A tuple result is compared member by member, with one bound per member
TTS_ULP_RANGE_CHECK(tts::between(1.f, 1000.f), float, float, std_frexp, my_frexp, 0., 0.);
};
